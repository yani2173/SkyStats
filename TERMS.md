# Terms of Use

SkyStats is a free desktop tool for flight simmers.

## Important Note

**This software is NOT for real-world aviation.** It is made strictly for virtual flight simulation and gaming (MSFS, X-Plane, Prepar3D on VATSIM). Never use it for real-world navigation or flight planning.
